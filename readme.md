
# Chapter Two Exam – Sensation and Perception

## Project Description

This is a web-based multiple-choice examination based on
Chapter Two of the General Psychology textbook.

Chapter Two topic: Sensation and Perception.

The exam contains 40 multiple-choice questions.
Each question has four options: A, B, C, and D.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Files

chapter2-exam/
|
|-- index.html
|-- style.css
|-- script.js
|-- README.md

## Features

1. 40 multiple-choice questions.
2. Four answer options per question.
3. Exam progress indicator.
4. Automatic marking.
5. Automatic score calculation.
6. Correct answers displayed after submission.
7. Explanations for answers.
8. Reset and try-again functions.
9. Responsive design for mobile and desktop.

## How to Run the Project

1. Create a folder called chapter2-exam.
2. Create the four files listed above.
3. Copy the corresponding code into each file.
4. Save all files in the same folder.
5. Open index.html using Google Chrome, Firefox,
   Microsoft Edge, or another web browser.
6. Answer the questions.
7. Click Submit Exam to see your result.

## Exam Scoring

Each correct answer gives one mark.

Total questions: 40
Total marks: 40

Percentage = (Correct Answers / 40) * 100
